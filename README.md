# dsh-pet —— uTools 桌面宠物

基于 uTools 平台开发的桌面宠物插件，用于实时展示 dsh（DeepSeek Harness）的任务状态，
并在需要用户处理时提供提醒。桌宠为独立悬浮窗口，可置顶常驻，不依赖浏览器页面。

任务数据通过 [dsh-tab-alert](https://github.com/Suef-666/dsh-tab-alert) 插件提供的
WebSocket 事件流获取（`ws://127.0.0.1:<端口>/tab-alert/stream`，协议说明见该仓库的
protocol.md）。

## 功能

- **状态面板**：以单一圆角矩形面板展示当前任务，包含任务标题与状态徽标。无任务时面板自动隐藏。
  - 思考 / 干活：显示"处理中…"（逐秒动画）
  - 回复中：AI 流式文本实时滚动
  - 等你：显示"提问 / 授权 / 审查"徽标及"等你操作"
  - 完成 / 出错：分别以绿 / 红徽标展示，数秒后自动收起
- **提醒**：任务进入"等你 / 完成 / 出错"状态时触发桌宠跳动与提示音，二者可独立开关。
- **拖拽**：窗口支持自由拖拽，兼容多显示器及不同缩放率。
- **右键菜单**：提供置顶、测试音效、关闭等操作。

## 安装

前提：dsh 中已安装 dsh-tab-alert 插件（安装方式见其仓库 README）。

1. 在 uTools 开发者模式下导入本插件目录；
2. 触发 `dsh桌宠` 并点击「创建桌宠」；
3. 如需常驻桌面，勾选设置中的"启动自动建宠"。

卸载：在 uTools 插件管理中移除即可。

## 配置

设置面板位于主窗口右上角（⚙ 图标）。

| 配置项 | 说明 |
|---|---|
| dsh 地址 | 事件流地址，默认 `http://127.0.0.1:3081` |
| 实时消息框 | 状态面板总开关 |
| 音效 / 音量 | 提醒音效及其音量 |
| 桌宠跳动 | 是否启用提醒时的跳动动画 |
| 置顶 | 窗口置顶显示 |
| 启动自动建宠 | 插件启动时自动创建桌宠 |

## 状态说明

| 徽标 | 说明 |
|---|---|
| 思考（紫）/ 干活（灰） | 任务处理中，显示"处理中…" |
| 回复中（青） | AI 流式回复，内容实时滚动 |
| 提问 / 授权 / 审查（橙） | 等待用户操作 |
| 完成（绿）/ 出错（红） | 任务结束，数秒后收起 |

## 常见问题

- **状态面板无显示**：检查桌宠左下角连接指示，红色表示未连上事件流。请确认
  dsh-tab-alert 已安装，并重启 dsh 使插件生效。
- **dsh 使用非默认端口**：在设置中修改 dsh 地址。
- **自定义宠物形象**：编辑 `pet/index.html` 中的宠物元素。

## 项目结构

```
dsh-pet/
├── plugin.json       uTools 插件清单
├── preload.js        主窗口 preload：悬浮窗创建与窗口控制
├── index.html        主面板：dsh 界面 + 设置 + 创建桌宠
└── pet/
    ├── index.html    桌宠窗口：宠物 + 状态面板 + WebSocket 直连 + 拖拽 + 菜单
    └── preload.js    桌宠窗口 preload：IPC 辅助
```
