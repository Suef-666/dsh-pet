# dsh-pet —— uTools 桌面宠物

一个挂在桌面的 uTools 悬浮窗：显示 dsh 当前任务的状态，需要你处理的时候提醒你。

任务数据来自 [dsh-tab-alert](https://github.com/Suef-666/dsh-tab-alert) 插件提供的
WebSocket 事件流（`ws://127.0.0.1:<端口>/tab-alert/stream`，协议见该仓库的 protocol.md）。
桌宠是独立窗口，不依赖浏览器页面，关掉主面板也能继续跑。

## 它能做什么

- **状态面板**：任务标题加状态徽标。思考/干活时显示"处理中…"（点号每秒循环），
  回复中直接滚动 AI 的流式文本，等你时显示"提问/授权/审查"和"等你操作"，
  完成/出错分别用绿/红徽标，几秒后自动收起。没有任务时面板不显示。
- **提醒**：状态变成"等你/完成/出错"时，桌宠跳一下、响一声。音效和跳动都可以在设置里单独关。
- **拖拽**：窗口可以拖到屏幕任何位置，多显示器、不同缩放率下也能跟手。
- **右键菜单**：置顶、测试音效、关闭。

## 怎么装

先装好 dsh-tab-alert（按它的 README 装），然后：

1. uTools 开发者模式 → 导入插件 → 选这个目录；
2. 触发 `dsh桌宠`，点「创建桌宠」。如果勾了"启动自动建宠"，以后启动插件会自动建。

卸载：uTools 插件管理里移除即可。

## 设置

主面板右上角 ⚙ 打开：

| 项 | 说明 |
|---|---|
| dsh 地址 | 事件流地址，默认 `http://127.0.0.1:3081` |
| 实时消息框 | 状态面板开关 |
| 音效 / 音量 | 提醒音效 |
| 桌宠跳动 | 提醒时桌宠跳不跳 |
| 置顶 | 窗口置顶 |
| 启动自动建宠 | 启动插件自动创建桌宠 |

## 状态说明

| 徽标 | 意思 |
|---|---|
| 思考（紫）/ 干活（灰） | 正在处理，显示"处理中…" |
| 回复中（青） | AI 流式回复，实时滚动 |
| 提问 / 授权 / 审查（橙） | 等你操作 |
| 完成（绿）/ 出错（红） | 任务结束，几秒后收起 |

## 常见问题

- 桌宠一直没状态：看左下角的小圆点，红色就是没连上事件流。检查 dsh 里 dsh-tab-alert
  装了没有、装完重启 dsh 没有。
- dsh 不是默认端口：设置里改 dsh 地址。
- 想换宠物形象：改 `pet/index.html` 里的宠物元素（默认 🐳）。

## 项目结构

```
dsh-pet/
├── plugin.json       uTools 插件清单
├── preload.js        主窗口 preload：悬浮窗创建与窗口控制
├── index.html        主面板：dsh 界面 + 设置 + 创建桌宠
└── pet/
    ├── index.html    桌宠窗口：宠物 + 状态面板 + WS 直连 + 拖拽 + 菜单
    └── preload.js    桌宠窗口 preload：IPC 辅助
```
