# dsh-pet —— uTools 桌面宠物（dsh 状态桌宠）

> 🚀 基于 [uTools](https://www.u-tools.cn/)（[uTools 开发者文档](https://www.u-tools.cn/docs/developer/)）插件机制开发，配合 [dsh-tab-alert](https://github.com/Suef-666/dsh-tab-alert) 实时事件源使用。

把 dsh（DeepSeek Harness）的任务状态带到桌面上：一只常驻的透明悬浮桌宠，随时告诉你
「AI 正在思考 / 在等你处理 / 任务完成 / 出错」，需要你时主动提醒——无论你切到哪个
软件都看得到。

## 特性

- **实时任务状态面板**：贴合桌宠的单一圆角矩形状态卡，无任务时自动隐藏，状态变化原地更新：
  - 思考 / 干活：`处理中 . .. ...` 逐秒动画
  - 回复中：AI 流式文本**实时滚动**
  - 等你：`提问 / 授权 / 审查` 橙色徽标 + `等你操作`
  - 完成（绿）/ 出错（红），数秒后自动收起
- **注意力提醒**：等你 / 完成 / 出错时桌宠跳动 + 提示音（实时消息框、音效、跳动均可独立开关）
- **流畅拖拽**：跨显示器、不同缩放率下精准跟手，位置随手即走
- **右键菜单**：切换置顶 / 测试音效 / 关闭
- **轻量设置**：⚙ 设置面板，所有功能开关一目了然

## 工作原理

```
dsh 宿主进程
  └─ dsh-tab-alert 插件（实时事件源中间件）
        └─ WebSocket 事件流  ws://127.0.0.1:<端口>/tab-alert/stream
             （连接快照 + 400ms 实时更新，协议见 dsh-tab-alert/protocol.md）
                   ▼
        本桌宠（uTools 悬浮窗，完全自包含）
        ├─ 单一状态面板：当前任务状态与 AI 回复
        ├─ 注意力提醒：等你 / 完成 / 出错 → 跳动 + 音效
        └─ 断线自动重连（3s），恢复后自动重建状态
```

桌宠是独立悬浮窗，直连 dsh 宿主事件流——不依赖浏览器页面，关掉主面板也能继续运行。

## 安装

**前置**：dsh 侧已安装 [dsh-tab-alert](https://github.com/Suef-666/dsh-tab-alert) 宿主插件（安装方式见其 README）。

1. uTools 开发者模式（`Alt+Space` → 设置 → 插件管理 → 开发者模式）；
2. 「导入插件」→ 选择本目录；
3. 触发 `dsh桌宠` → 点「创建桌宠」（勾选"启动自动建宠"可常驻随启）。

> 卸载：uTools 插件管理 → 移除 dsh 桌宠 即可，不留后台残留。

## 设置（⚙）

| 项 | 说明 |
|---|---|
| dsh 地址 | 事件流地址（默认 `http://127.0.0.1:3081`） |
| 实时消息框 | 状态面板总开关 |
| 音效 / 音量 | 注意力提醒音效与音量 |
| 桌宠跳动 | 注意力提醒的跳动动画 |
| 置顶 | 桌宠窗口置顶 |
| 启动自动建宠 | 插件启动即自动创建桌宠 |

## 状态对照

| 徽标 | 含义 |
|---|---|
| 思考（紫） | 正在思考 |
| 干活（灰） | 工具调用中（处理中…） |
| 回复中（青） | AI 流式回复中 |
| 提问 / 授权 / 审查（橙） | 等你操作 |
| 完成（绿） | 任务完成 |
| 出错（红） | 任务出错 |

## 常见问题

- **桌宠没有状态显示**：观察桌宠左下角连接点——红色表示未连上事件流，请确认
  dsh 已安装并重启 dsh-tab-alert 插件；
- **dsh 跑在 Docker / 自定义端口**：保持端口映射，在设置中修改 dsh 地址；
- **想自定义桌宠形象**：编辑 `pet/index.html` 中的宠物元素（默认 🐳）即可。

## 项目结构

```
dsh-pet/
├── plugin.json       uTools 插件清单（platform: win32）
├── preload.js        主窗口 preload：悬浮窗创建与窗口控制
├── index.html        主面板：dsh 界面嵌入 + ⚙ 设置 + 创建桌宠
└── pet/
    ├── index.html    桌宠窗口：宠物 + 状态面板 + WS 直连 + 拖拽 + 右键菜单
    └── preload.js    桌宠窗口 preload：IPC 辅助
```

## Roadmap

- **独立 Electron 套壳**：不依赖 uTools 的独立应用外壳（逻辑层已与 uTools API 解耦，可直接迁移）；
- **宠物表现**：更多动画与情绪状态、宠物形象可切换；
- **交互增强**：点击面板跳转对应会话、气泡跟随、目标进度条；
- **通知能力**：消息历史、免打扰时段、自定义提醒规则；
- **跨平台**：macOS / Linux。
